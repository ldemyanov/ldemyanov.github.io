# Портфолио Леонида Демьянова

Личный сайт Леонида Демьянова — fullstack-разработчика из Астаны. Здесь собраны проекты, опыт, направления работы и способы связи. Сайт опубликован на [ldemyanov.github.io](https://ldemyanov.github.io).

Сайт собирается Astro в статические HTML, CSS и JavaScript. Для просмотра страниц не нужен сервер приложения. Форма контактов отправляет обращения через Web3Forms.

## Содержание сайта

- **Главная** — краткое представление, компании, подход к работе, навыки и избранные проекты.
- **Обо мне** — опыт, подход и технологии.
- **Работы** — карточки и подробные описания проектов.
- **Услуги** — направления работы и подробные страницы услуг.
- **Контакты** — форма, мессенджеры, почта, телефон и резюме.
- **Конфиденциальность** и **Условия использования** — сведения об обработке данных и материалах сайта.

Раздел блога сейчас не опубликован. В коллекции хранится одна черновая запись для будущей статьи.

## Технологии

Astro 7, TypeScript, Markdown и обычный CSS. В браузере используются небольшие скрипты без клиентского UI-фреймворка. Карта сайта создаётся интеграцией @astrojs/sitemap. Шрифты Unbounded и IBM Plex Sans хранятся локально.

Список прямых зависимостей и их назначение приведены в [документе о стеке](spec/stack-and-dependencies.md).

## Локальный запуск

Нужны Node.js 22.12 или новее и npm.

~~~bash
npm ci
npm run dev
~~~

Адрес разработки: http://localhost:4321/.

Для работы формы скопируйте **.env.example** в **.env** и укажите значение **PUBLIC_WEB3FORMS_ACCESS_KEY**. Без ключа форма отключена; остальные страницы работают. Файл **.env** исключён из Git.

Основные команды:

| Команда | Назначение |
| --- | --- |
| npm run dev | Локальный сервер Astro |
| npm run build | Создание сайта в папке dist и проверка локальных ссылок |
| npm run check:links | Повторная проверка ссылок в уже собранной папке dist |
| npm run preview | Локальный просмотр собранного сайта |
| npm run check | Проверка типов и компонентов Astro |
| npm run sync | Обновление типов коллекций |

## Где менять содержимое

- Общие сведения, контакты и адрес Open Graph изображения — **src/config/site.ts**.
- Тексты основных блоков главной — **src/data/highlights.ts**.
- Компании, навигация и технологии — соответствующие файлы в **src/data/**.
- Кейсы — Markdown-файлы в **src/content/projects/**; имя файла становится адресом страницы в **/work/**.
- Услуги — Markdown-файлы в **src/content/services/**; имя файла становится адресом страницы в **/services/**.
- Схемы полей кейсов и услуг — **src/content.config.ts**.
- Цвета и размеры — **src/styles/tokens.css**; стили блоков — **src/styles/sections.css**.
- Изображения — **public/images/**; SVG-иконки и логотипы — **public/icons/**.

Строковые значения в YAML frontmatter заключайте в двойные кавычки. Это правило и пример записаны в [AGENTS.md](AGENTS.md).

## Сборка и публикация

Команда **npm run build** создаёт папку **dist/** со всеми статическими страницами и копиями файлов из **public/**, затем проверяет локальные ссылки в HTML, CSS, sitemap и манифесте. Если файл или страница отсутствует, сборка завершается с ошибкой и публикация не запускается. Скрипт проверки — **scripts/check-local-links.mjs**. Адрес сайта задан в **astro.config.mjs**: https://ldemyanov.github.io. Там же подключена генерация sitemap. Файл **src/pages/robots.txt.ts** создаёт robots.txt.

Workflow [deploy.yml](.github/workflows/deploy.yml) запускается при отправке изменений в ветку **main** и вручную через GitHub Actions. Он устанавливает зависимости, собирает сайт и публикует **dist/** в GitHub Pages. Для формы в настройках репозитория нужен секрет Actions **PUBLIC_WEB3FORMS_ACCESS_KEY**: он передаётся на этапе сборки. Этот ключ включается в итоговый HTML, потому что форма работает в браузере.

Подробное описание сборки, секретов и шагов workflow — в [документе о публикации](spec/github-build-and-deploy.md).
