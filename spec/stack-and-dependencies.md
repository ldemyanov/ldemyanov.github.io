# Стек и зависимости

Этот документ описывает технологии, на которых построено само портфолио. Технологии, перечисленные на страницах кейсов и навыков, относятся к опыту разработчика и не обязательно используются в коде сайта.

## Основа сайта

| Технология | Где и зачем используется |
| --- | --- |
| **Astro 7** | Компоненты и файловые маршруты в **src/**, статическая генерация всех страниц |
| **TypeScript** | Типы данных, конфигурация, скрипты компонентов и проверка коллекций |
| **Markdown** | Статьи проектов и услуг в **src/content/** |
| **CSS** | Стили без CSS-фреймворка; дизайн-переменные в **src/styles/tokens.css** |
| **JavaScript и Canvas API** | Меню, прокрутка, форма и интерактивный фон на главной; клиентского UI-фреймворка нет |
| **Unbounded и IBM Plex Sans** | Локальные шрифты из **public/fonts/**, подключены в **src/styles/fonts.css** |

## Прямые зависимости npm

Версии задаются в **package.json**, точные версии установки зафиксированы в **package-lock.json**.

| Пакет | Роль |
| --- | --- |
| **astro** | Разработка и сборка статического сайта, рендеринг компонентов и коллекций |
| **@astrojs/sitemap** | Создание sitemap при сборке |
| **@astrojs/check** | Команда **npm run check** для проверки компонентов и типов Astro |
| **typescript** | Строгая типизация и проверка TypeScript |

Первые два пакета — зависимости сайта; последние два нужны для разработки. Дополнительные библиотеки интерфейса, иконок или управления состоянием не установлены. Публичные SVG-иконки хранятся в **public/icons/**, а общие интерфейсные символы — в **src/components/icons/IconSprite.astro**.

Скрипт **scripts/check-local-links.mjs** использует только встроенные модули Node.js. Он запускается после Astro build и проверяет пути в готовом сайте; отдельной npm-зависимости для этого нет.

## Внешние сервисы и инструменты публикации

| Сервис или инструмент | Назначение |
| --- | --- |
| **Web3Forms** | Принимает данные формы контактов из браузера; ключ поступает в сборку через **PUBLIC_WEB3FORMS_ACCESS_KEY** |
| **GitHub Pages** | Размещает статические файлы сайта по адресу **ldemyanov.github.io** |
| **GitHub Actions** | Устанавливает зависимости, собирает проект и публикует результат |
| **actions/checkout@v4** | Получает исходный код в workflow |
| **actions/setup-node@v4** | Устанавливает Node.js 22 и включает кэш npm |
| **actions/configure-pages@v5** | Подготавливает окружение Pages |
| **actions/upload-pages-artifact@v3** | Загружает папку **dist/** как артефакт публикации |
| **actions/deploy-pages@v4** | Развёртывает артефакт в GitHub Pages |

Другие данные формы, включая имя, адрес электронной почты и текст сообщения, обрабатываются по правилам, описанным на странице **/privacy/**. Настройка сборки подробнее описана в [github-build-and-deploy.md](github-build-and-deploy.md).
