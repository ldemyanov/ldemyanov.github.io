# Как добавить блог

Сейчас журнал выключен: в коллекции оставлен только `src/content/blog/article-template.md`, компонент `src/components/home/Journal.astro` не подключён на главной, маршрутов `/journal/` пока нет. Компонент карточки и стили сохранены. Чтобы запустить блог, пройди шаги ниже.

### 1. Создать статью

Скопировать `src/content/blog/article-template.md` в новый файл с постоянным URL-именем, например `src/content/blog/kak-ustroen-kesh.md`. Имя файла становится `id` записи и сегментом адреса: `/journal/kak-ustroen-kesh/`. Использовать латиницу в нижнем регистре и дефисы; после публикации не переименовывать файл без редиректа.

Заполнить frontmatter по схеме в `src/content.config.ts`: `title`, `description`, `pubDate`, `category`, `readingTime`, `author`, `tags` и `image` (`src`, `alt`, `width`, `height`). Для готовой статьи поставить `draft: false`; у шаблона оставить `draft: true`. Путь `image.src` задавать от корня сайта, например `/images/blog/kesh.webp`.

### 2. Добавить страницу списка `/journal/`

Создать `src/pages/journal/index.astro`. Страница получает `await getCollection('blog')`, исключает черновики для production, сортирует по `pubDate` от новых к старым и выводит карточки через `PostCard.astro`. Использовать `PageLayout` или `BaseLayout` с заголовком и описанием страницы. Ссылку «Все статьи» в компоненте `Journal.astro` направлять именно на `/journal/`.

### 3. Добавить статические страницы публикаций

Создать `src/pages/journal/[slug].astro`. В `getStaticPaths()` получить опубликованные записи из `getCollection('blog')` и для каждой вернуть `params: { slug: post.id }` и `props: { post }`. Например, `kak-ustroen-kesh.md` даст `/journal/kak-ustroen-kesh/`. На странице вызвать `render(post)`, вывести `<Content />` внутри `.prose`, а `title`, `description`, обложку и дату взять из frontmatter. Добавить ссылки на `/journal/` и навигацию к соседним статьям.

Сортировку для навигации по статьям выполнять по `pubDate`. Для текущей записи найти индекс в отсортированном списке; соседние ссылки строить по `post.id`, а на краях списка скрывать отсутствующую ссылку. Не собирать адреса из заголовков: только `id` Markdown-файла должен определять URL. В проекте включён `trailingSlash: 'always'`, поэтому внутренние ссылки должны оканчиваться `/`.

Для всех ссылок использовать один небольшой helper, например `journalPostPath(id) => \`/journal/${id}/\``, и вызывать его в карточке, списке и ссылках «предыдущая/следующая». Так адреса не разойдутся между страницами. Если статьи будут лежать во вложенных папках, использовать маршрут `[...slug].astro` и одинаково обрабатывать вложенный `post.id` в `getStaticPaths()` и helper.

### 4. Подключить блог на главной и в навигации

В `src/pages/index.astro` раскомментировать импорт `Journal` и `<Journal />`. Компонент показывает последние три записи; перед отображением исключить шаблон (`draft: true`) и отсортировать публикации по дате. Если опубликованных статей нет, не выводить пустую секцию.

Добавить пункт «Блог» с `href: '/journal/'` в `primaryNav` в `src/data/navigation.ts`. При необходимости добавить эту же ссылку в `footerNav.explore`. Проверить, что переход по ссылке работает как с главной, так и с внутренних страниц; для якорей главной уже используется отдельное поле `anchor`, но для блога оно не нужно.

### 5. Перед публикацией

- Убедиться, что `article-template.md` остаётся черновиком и не попадает в список, статические маршруты и sitemap.
- Проверить совпадение `post.id`, URL карточки, URL страницы статьи и URL соседних ссылок.
- Проверить адреса с завершающим `/`, изображения и ссылки «Блог» в шапке и футере.
- После добавления файлов Astro автоматически включит сгенерированные статические страницы в сборку и sitemap интеграции; отдельный сервер или API для блога не нужен.
